## Highlights

- The starter now ships a real Android home-screen widget: entry count and summary, tap to open
  the app, data pushed one-way from Dart through a single method channel.
- A release skill (`.agents/skills/release`) turns merge, branch cleanup, publish, CI watch and
  reporting into one repeatable path.
- Design decisions moved out of `docs/`: proposals, accepted decisions and rejected options live
  under `.agents/notes`, so `docs/` keeps describing only the current state.
- An installable arm64 APK is attached to every release, so the template can be tried on a phone
  before creating a project from it.

## Upgrade note

First public release of the template; there is nothing to upgrade from.

Install this build on any arm64 Android 8.0+ device. It is a demo app: entries are stored locally
and can be added, edited and deleted from the main screen.

SHA-256 is published next to the APK.
